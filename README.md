# FAREED Responsive Website

A responsive clothing-brand website built for the New Horizon HTML, CSS and JavaScript practical assignment.

## Project overview
FAREED is presented as an independent clothing label focused on accessible, modern, functional everyday clothing. The website includes Home, About, Collection and Contact sections.

## Project files
- `index.html` — page structure and content
- `style.css` — layout, colours, typography, Flexbox, Grid and responsive media queries
- `script.js` — mobile navigation, current year and contact-form validation

## Run locally
1. Download or clone this repository.
2. Keep all three files in the same folder.
3. Open `index.html` in a modern web browser.

The Google Fonts import requires an internet connection; the page has fallback fonts if they cannot load.

## Deployment
This is a static website. Upload the project folder or connect the GitHub repository to Netlify or Render. Publish the folder containing `index.html`, `style.css` and `script.js`.

## Before submission
- Replace the sample email and phone number with real or clearly identified sample details.
- Check all text, product names and illustrative prices.
- Test the website on a phone and desktop.
- Create a GitHub repository and make regular commits.
- Deploy the site and submit both the repository URL and public live URL.

## Important functionality note
The contact form performs browser-side validation only. It does not send or store messages because no backend or form-submission service is connected.
